# 小批量标签拼版 Web 工具

输入纸张尺寸、页边距、多种标签的宽高与份数、裁切间距及是否允许旋转，
自动在每张纸上安排**互不重叠**的位置；放不下自动续页，并显示每种标签
实际排入数量。预览与可下载打印的 SVG 使用**同一套毫米坐标**，页边距与
间距在导出中完全一致。

支持**打印位置校准**：下载一张含横、纵两组基准刻线的测试页，100% 缩放
打印后量取各刻线在纸上的实际坐标，软件分别拟合 X / Y 方向的线性走纸误差；
下载及打印 SVG 时按误差的**逆变换**修正标签轮廓、裁切线与标注，让打印
结果落回设计位置。页面常规预览与 `/api/layout` 的坐标、数量保持原样。

支持**复用首张已贴过标签的纸张**：为第一张纸配置若干「占用区」
（左上角 x/y、宽、高，单位毫米），排版时作为障碍避让，新标签与其
保持设定的裁切间距；第一页放不下的份数自动续到后续空白页。预览中
占用区以灰色显示，下载 / 打印的 SVG 只包含新标签。

支持**每规格可选流水号**（前缀 + 起始整数 + 补零位数）：排版后按
**页码、页内从上到下再从左到右**的实际位置为每种标签独立连续编号，
旋转 90°、首页占用区避让与续页都不会跳号或重号，未排入的份数不消耗
编号。预览、下载与打印的 SVG 在标签内部显示同一编号；编号在最小
字号下仍放不进标签时返回明确中文错误（HTTP 400），绝不输出越界文字。
界面汇总表显示各规格本次实际编号范围；未启用编号的标签保持原有
「名称 + 尺寸」标注。

支持**原位补印**：个别标签漏印或损坏时，在预览中开启「原位补印模式」
按页点选需要重印的标签（页内序号从 1 开始），导出**只含选中标签**的
补印 SVG——服务端仍计算完整原排版，再只绘制选中标签的轮廓、编号、
标注与裁切角线，坐标与流水号保持原排版不重排、不重新编号；未选位置、
页码标记与页边距线均留白，把原纸放回打印机即可原位重印。补印导出
同样应用打印校准补偿；选择为空或序号越界时返回明确中文错误。

支持**纸张库存领料**：按纸宽 × 纸高（毫米）登记纸张库存并随时查看各
纸型余量；「确认领料」时服务端用当前参数**重新计算拼版**，仅当所有
标签全部排入、且纸张宽高与库存纸型**完全一致**时，才按**实际页数**
在单个 SQLite 事务内完成库存核对、余量扣减与领料记录写入。同一领料
单号 + 同一参数重试只返回原记录、**不重复扣纸**；单号相同但参数变化
返回冲突（HTTP 409）；库存不足时错误信息同时给出所需页数与当前余量。
已确认领料单可**作废并退纸**：按原单实际扣纸页数把对应纸型返还库存，
原单保留作废时间与返还张数；回补与状态变更在同一 SQLite 事务中完成，
重复点击或并发请求**只返还一次**；作废后的单号不能再次用于确认领料。
库存与领料记录通过 Docker Compose 命名卷持久化。

技术栈：Python 3.11 + FastAPI + SQLite（标准库，零额外依赖）+ 原生
HTML / CSS / JavaScript（无前端构建）。

## 一条命令启动

无需任何额外配置（仅需 Docker / Docker Compose；SQLite 为 Python 标准库，
无需另装数据库）。在项目根目录执行：

```bash
docker compose up --build
```

启动后浏览器访问：

- **http://localhost:8000**
- API 文档（Swagger）：**http://localhost:8000/docs**

端口通过 `docker-compose.yml` 固定映射 `8000:8000`；如本机 8000 端口
被占用，将其中左侧端口改为其它值（例如 `18000:8000`）后重新启动即可。
停止：`Ctrl+C`，或在另一个终端执行 `docker compose down`。

库存与领料记录保存在容器内 `/app/data/label_stock.db`（SQLite），
通过命名卷 `label-stock-data` 持久化：`docker compose up --build`
重建容器后数据仍在；如需彻底清空，执行
`docker compose down -v`（会同时删除数据卷）。

> 容器启动时会自动执行：安装依赖 → 初始化自检（排版、SVG 生成、
> 打印校准与库存领料事务的冒烟测试）→ 启动 uvicorn。

## 功能说明

- **纸张**：内置 A4 / A5 / Letter 纵横预设，也可自定义任意毫米尺寸。
- **页边距**：上 / 右 / 下 / 左独立设置。
- **裁切间距**：水平、垂直分别设置；间距只出现在相邻标签之间，
  纸边不留多余半格。
- **裁切角线自动避让**：每个标签四角画外扩 1.5mm、单臂 3mm 的红色
  裁切角线，并对 8 段角线**逐段求可绘部分**——
  - 与本页其他标签轮廓相交的段裁到标签边缘为止，因此标签以 0mm
    间距紧贴时角线不会画进邻签；
  - 与首页「占用区」相交的段同样裁去（即使下载 / 打印的 SVG 不画
    占用区，角线也会正确避让）；
  - 落在纸张范围之外的段裁去，靠近纸边时不会画出纸面；
  - 裁切后残段短于 **0.5mm** 的整段省略，避免出现无意义的小短线；
  - 角线避让只改角线本身，**标签轮廓、排版数量与位置保持原样**。
  预览与下载 / 打印共用同一套裁切规则（均由后端 `POST /api/svg`
  生成）；应用走纸校准时，按逆变换**补偿后的坐标**判定邻签、首页
  占用区与纸边，避让结果与打印落位一致。
- **多种标签**：任意行数，每行设置名称、宽 (mm)、高 (mm)、份数、
  是否允许旋转 90°；勾选「编号」后展开该规格的**流水号设置**
  （前缀、起始整数、补零位数）。
- **连续流水号（可追溯编号，可选）**：
  - 每种标签独立编号，互不干扰；勾选「编号」后填写三项：
    - **前缀**：任意文本（最多 20 个字符），如 `P-`、`SN`；留空则纯数字；
    - **起始整数**：第一个**实际排入**标签使用的整数，必须 ≥ 0
      （如填 `100` 则从 100 开始）；
    - **补零位数**：数字部分左侧补 0 的最小位数，`0` 表示不补零；
      实际位数超出时不截断（如补零 2 位、序号 100 → `100`）。
  - 编号顺序 = **页码升序 → 页内从上到下成行 → 同排从左到右**，
    即排版后标签的实际阅读位置；
  - 旋转只改变标签宽高方向，不影响序号；首页占用区把标签挤到
    别处或挤到续页，序号仍连续——**同规格不跳号、不重号**；
  - **未排入的份数不消耗编号**：标签过大全部排不下时该规格本次
    没有编号范围；排下一部分时范围只覆盖实际排入数量；
  - 预览、下载与打印的 SVG **同源**（都由 `/api/svg` 生成），
    同一标签内显示完全相同的编号；编号在标签内自动选最大可读字号
    （1.8–6mm），并按纸张补偿后的内框校验；最小字号仍放不下时
    `/api/svg` 返回 HTTP 400 与明确原因（标签、编号、内框尺寸），
    界面预览区与下载弹窗都会提示，**不会生成文字越界的 SVG**；
  - 汇总表新增「本次编号范围」列，如 `P-001 – P-020`；只排到一个
    时显示单个编号，全部未排入时提示「不消耗编号」；
  - 未勾选「编号」的规格：`numbering` 为 `null`，标签内部保持原有
    名称 / 尺寸灰色标注，行为与旧版完全一致。
- **首张纸占用区（复用已贴纸的纸）**：
  - 在「首张纸占用区」中添加任意多个矩形，填写**左上角 X、左上角 Y、
    宽、高**（均为毫米，原点在纸张左上角），可随时编辑或删除；
  - 占用区必须完全在纸张范围内，越界（含负坐标、右边/下边超出纸张）
    会在前端与接口处给出明确错误，不生成排版；
  - 新标签把占用区当作障碍，无论从左、右、上、下接近，都至少保持
    设定的水平 / 垂直裁切间距；多个占用区可以重叠；
  - 第一页排不下的份数自动续到后续**空白页**，统计不丢失、不重复；
  - 占用区完全落在页边距区域内时不报错，仅提示“不影响排版”。
- **自动排版**：天际线（skyline）左下角装箱，标签位置互不重叠；
  当前页放不下自动续页；允许旋转时会尝试 90° 方向。
- **排入统计**：表格列出每种标签的需求数、实际排入数、旋转数、未排入数；
  单张标签超过可排区域时给出明确提示。
- **预览 / 导出同源**：浏览器预览和下载的 SVG 都由后端
  `POST /api/svg` 基于同一份排版结果生成，单位均为毫米。预览第一页以
  **灰色斜纹**绘制占用区；下载 / 打印的 SVG **只含新标签**，
  两者标签坐标完全一致。
- **导出**：支持「下载本页 SVG」「下载全部页」，以及按纸张精确尺寸
  排版的「打印全部页」（`@page size` 等于纸张毫米尺寸，无边距）。
- **原位补印（按页点选补印）**：
  - 在预览工具栏勾选「原位补印模式」后，本页每个标签出现可点击的
    选框与页内序号角标（`#1`、`#2`……，序号从 1 开始，与
    `/api/layout` 返回的 `pages[].labels[]` 顺序一致）；点击即可
    选中 / 取消漏印或损坏的标签，选中以橙色高亮；
  - 状态栏实时显示**本页已选数量**（如 `本页已选 2 / 20 个`），
    跨页选择会提示其他页的选中数，但补印导出始终只针对**当前页**；
    「清空本页选择」可一键重来；重新「生成拼版」后所有选择自动清空；
  - 点击「导出本页补印 SVG」下载 `reprint-page-N.svg`：服务端按当前
    参数**重新计算完整原排版**，再只绘制选中标签的轮廓、流水号、
    标注与裁切角线——**坐标与编号取自完整排版，不重排、不重新编号**；
    未选标签位置、页码标记与页边距线全部留白（裁切角线仍按完整版面
    避让未选标签与首页占用区，不会画进已印好的标签上）；
  - 勾选「应用校准补偿」时，补印 SVG 与整页导出一样按逆变换修正
    坐标；补偿后出界校验只针对选中标签；
  - 本页未选择任何标签、或序号 / 页码超出范围时，界面与接口均给出
    明确中文错误（HTTP 400），不生成 SVG；
  - 普通预览、「下载本页 / 全部页」「打印全部页」行为完全不变。
- **打印位置校准（可选，只影响下载 / 打印）**：
  - 点击「① 打开 / 下载校准测试页」，按当前纸张尺寸生成测试页
    （5 条纵向实线 X1–X5 沿纸宽均布、5 条横向虚线 Y1–Y5 沿纸高均布，
    每条刻线旁标注设计坐标；页面标题提示 100% 缩放打印）；
  - 打印后用尺测量每条刻线的纸上位置：竖线量到纸张**左缘**、
    横线量到纸张**顶缘**（毫米），填入「实测」列，设计坐标由软件按
    当前纸张自动填入；
  - 点击「② 计算 X / Y 校准参数」，软件对两组数据分别做最小二乘
    拟合，得到线性走纸误差 `实测坐标 = 缩放 × 设计坐标 + 偏移`，
    并显示 X / Y 的缩放与偏移；
  - 勾选「应用校准补偿」后，「下载 SVG」「下载全部页」「打印全部页」
    的标签轮廓、裁切线、标注、页边距线等全部按逆变换
    `(设计 − 偏移) / 缩放` 逐点修正（线宽、字号不变），打印机再走
    一遍误差后内容恰好落回设计位置；裁切角线的避让判定也在补偿后
    的坐标空间进行——按补偿后的位置判断邻签与首页占用区、按补偿后
    的纸边上裁，不会在修正后的纸上侵入邻签或画出纸外；
  - **页面常规预览与 `/api/layout` 不携带校准参数**，坐标、页数与
    标签数量保持原样；
  - 出现以下情况时阻止校准导出并返回明确中文原因（HTTP 400）：
    1. **基准点重合**——设计坐标重复或实测坐标全部相同，无法拟合；
    2. **实测顺序颠倒**——实测值未随设计坐标递增（如从右往左 /
       从下往上读数或刻线对错位）；
    3. **补偿后内容超出纸张**——逆变换使任一标签的修正位置越出
       纸张边界，错误信息给出该标签与修正后坐标。
- **纸张库存与领料**（页面右下方面板）：
  - **登记库存**：按「纸宽 (mm) × 纸高 (mm) + 入库张数」登记，
    纸宽 / 纸高统一保留 2 位小数；同一纸型重复登记**累加余量**，
    「当前库存余量」表实时列出每种纸型的余量与最近入库时间，
    也可用「用左侧当前纸张尺寸填入」一键带入拼版纸型；
  - **确认领料**：填写领料单号（打开页面自动生成
    `LL-YYYYMMDD-HHMMSS`，可手动修改或「换一个」），点击
    「确认领料并扣纸」——服务端用**左侧表单当前参数重新计算拼版**，
    前端预览的页数不参与判定：
    1. 所有标签**全部排入**（任一标签有未排入份数则拒绝，HTTP 400）；
    2. 拼版纸宽、纸高与库存纸型**完全一致**（宽、高方向分别精确匹配，
       不自动旋转纸型；未登记视为余量 0）；
    3. 余量 ≥ 实际页数；
    三者同时满足才扣纸，扣除张数 = 服务端重算的**实际页数**；
  - **SQLite 事务**：库存核对、余量扣减、领料记录写入在同一个
    `BEGIN IMMEDIATE` 事务中原子提交，失败整体回滚，不会出现扣了纸
    却没记录或库存为负；
  - **重试幂等**：同一领料单号 + 相同参数再次提交，返回原领料记录
    （响应中 `reused=true`，HTTP 200），**不重新计算扣纸**、余量不变；
    单号相同但参数变化返回 **HTTP 409 冲突**，明确提示原记录内容；
  - **库存不足提示**：错误信息同时给出本次实际所需页数、当前余量与
    差额（或纸型未登记时提示余量 0 张），例如：
    `纸型 210×297mm 库存不足：本次拼版实际需要 6 张，当前余量仅 4 张，
    还差 2 张；请补登记库存后重试。`
  - 页面下方展示本次确认结果（用纸页数、排入数、扣减前后余量）与
    **近期领料记录**（最近 10 条：单号、纸型、页数、排入、余量变化、
    **状态**、确认 / 作废时间、操作）；数据保存在 SQLite 并通过 Compose
    命名卷持久化。
  - **作废并退纸（操作入口：近期领料记录表「操作」列的「作废并退纸」
    按钮，仅未作废单显示）**：
    1. 点击后二次确认，作废在单个 `BEGIN IMMEDIATE` 事务内完成——
       按**原单实际扣纸页数**（`pages_required`）把对应纸型张数加回
       库存，同时把单据状态置为「已作废」、写入作废时间与返还张数，
       库存回补与状态变更要么全部生效要么全部回滚；
    2. 原单**不删除**：单号、纸型、用纸页数、原扣减前后余量快照与
       确认时间全部保留，新增作废时间、返还张数与回补前后余量；
    3. **只返还一次**：作废使用条件更新
       `WHERE status='confirmed'`，重复点击按钮或多个并发请求同时作废
       同一单号时，只有第一个请求真正退纸，其余直接返回原作废记录
       （`already_voided=true`，HTTP 200），库存不会被重复加回；
    4. 作废成功后界面自动刷新**库存余量**与领料记录，状态列显示
       「已作废」，作废行显示返还张数、返还后余量与作废时间；
    5. **作废后的单号永久失效**：再用该单号确认领料（无论参数是否与
       原单相同）一律 HTTP 409 拒绝并提示已作废信息，请使用新单号；
    6. 作废不存在的单号返回 HTTP 404 及明确中文提示。

## 接口

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET  | `/health` | 健康检查 |
| POST | `/api/layout` | 提交参数（含首张纸 `occupied_zones`、每规格可选 `numbering`），返回分页排版结果（毫米坐标、每个已排入标签的 `serial`、各规格 `number_first/number_last`）；**不涉及校准，坐标/数量恒为原始结果** |
| POST | `/api/svg` | 提交参数 + 页码 + 显示开关 + 可选 `calibration` 校准数据，返回该页 SVG；启用编号时在标签内绘制 `serial`，编号放不进标签返回 HTTP 400；提供 `calibration` 时按逆变换修正坐标 |
| POST | `/api/reprint` | 原位补印：提交参数 + `page` 页码 + `indexes` 页内标签序号（从 1 开始）+ 可选 `calibration`，返回**只含选中标签**的补印 SVG（轮廓、编号、标注、裁切角线；页码与边距线留白）；选择为空或序号越界返回 HTTP 400 |
| GET  | `/api/calibration/page?page_width=&page_height=` | 下载校准测试页 SVG（横、纵两组基准刻线） |
| GET  | `/api/calibration/marks?page_width=&page_height=` | 返回测试页两组基准刻线的设计坐标 JSON（界面自动填表） |
| POST | `/api/calibration/solve` | 提交两组「设计 / 实测」刻线坐标，返回 X / Y 拟合结果 `scale`、`offset` |
| GET  | `/api/stock` | 查看全部纸型当前余量（纸宽、纸高、张数、最近入库时间） |
| POST | `/api/stock` | 按 `paper_width` / `paper_height` / `quantity` 登记入库；同纸型累加余量，返回该纸型最新余量 |
| POST | `/api/requisitions` | 确认领料：`{order_no, params}`，服务端用 params 重算拼版，全部排入且纸型匹配、余量充足时在 SQLite 事务内按实际页数扣纸并写记录；成功 HTTP 201，同单号同参数重试返回 HTTP 200 + 原记录（`reused=true`）不重复扣纸，同单号参数变化 / **单号已作废** / 纸型未登记 / 余量不足返回 HTTP 409，有标签未排入或拼版参数非法返回 HTTP 400 |
| POST | `/api/requisitions/void` | 作废领料单并退纸：`{order_no}`，在 SQLite 事务内按原单 `pages_required` 返还对应纸型并把状态置为 `voided`（写入 `voided_at`、`returned_pages` 与回补前后余量）；HTTP 200，重复 / 并发作废同一单号只返还一次（其后响应 `already_voided=true`），单号不存在返回 HTTP 404 |
| GET  | `/api/requisitions?limit=10` | 近期领料记录（最新在前，默认 10 条，最多 100 条；含 `status`（`confirmed`/`voided`）、`voided_at`、`returned_pages`、`restock_before/after`） |

`/api/svg` 在服务端重新计算同一份排版，保证导出坐标与预览一致。
其 `show_occupied` 开关仅预览时为 `true`（第一页灰色绘制占用区）；
下载 / 打印时为 `false`，SVG 中只包含新标签。界面的常规预览请求
**不带** `calibration`，仅「下载 / 打印」动作携带。`/api/reprint`
同样重新计算完整排版后再筛选绘制，补印坐标、编号与整页导出逐点一致。
API 文档（Swagger）：http://localhost:8000/docs

### 校准数据格式

`/api/svg` 的 `calibration` 字段与 `/api/calibration/solve` 的请求体相同：

```json
{
  "x_lines": [
    {"design": 21.0, "measured": 21.3},
    {"design": 63.0, "measured": 63.2}
  ],
  "y_lines": [
    {"design": 29.7, "measured": 30.0},
    {"design": 89.1, "measured": 89.4}
  ]
}
```

每组至少 2 条；`x_lines` 为纵向刻线（校准 X），`y_lines` 为横向刻线
（校准 Y）。拟合结果形如
`{"x": {"scale": 1.0012, "offset": 0.08}, "y": {"scale": 0.998, "offset": 0.2}}`。
基准点重合、实测顺序颠倒由 solve 与 svg 两个接口共同拦截；
补偿后内容超出纸张仅在 `/api/svg` 拦截（需结合具体排版）。

### 请求示例

```json
{
  "page_width": 210,
  "page_height": 297,
  "margin_top": 8,
  "margin_right": 8,
  "margin_bottom": 8,
  "margin_left": 8,
  "gap_x": 2,
  "gap_y": 2,
  "labels": [
    {"name": "品名标签", "width": 60, "height": 30, "count": 20, "allow_rotate": true,
     "numbering": {"prefix": "P-", "start": 1, "pad": 3}},
    {"name": "箱贴", "width": 100, "height": 70, "count": 6, "allow_rotate": false,
     "numbering": null}
  ],
  "occupied_zones": [
    {"x": 48, "y": 48, "width": 100, "height": 100}
  ]
}
```

`occupied_zones` 为可选数组，仅作用于第一页；每项的 `x` / `y` 为
占用区左上角相对纸张左上角的坐标，`width` / `height` 为其尺寸。
越界（`x + width > page_width`、`y + height > page_height` 或坐标为负）
返回 HTTP 400 及明确中文错误，例如：

```text
占用区 1越界：x(120.0) + 宽(100.0) = 220.0mm 超过纸张宽度 210.0mm。
```

### 流水号格式

每个标签规格的 `numbering` 字段为 `null`（不编号）或对象：

```json
{"prefix": "P-", "start": 1, "pad": 3}
```

| 字段 | 含义 | 约束 |
| ---- | ---- | ---- |
| `prefix` | 编号前缀，原样拼在数字前 | 字符串，最多 20 个字符，可空 |
| `start` | 起始整数（**实际排入**的第一个标签） | 整数，≥ 0 |
| `pad` | 数字部分最小补零位数 | 整数 0–12；`0` 不补零，位数超出不截断 |

最终编号 = `prefix` + `str(整数).zfill(pad)`，如 `P-` + `1` + `3 位` → `P-001`。
`/api/layout` 响应中：

- `pages[].labels[].serial`：该标签的最终编号字符串；未启用编号的规格为 `null`；
- `summaries[].numbered`：是否启用编号；
- `summaries[].number_first` / `number_last`：本次**实际排入**的首、末编号
  （该规格一个都没排下时两者均为 `null`，表示未消耗任何编号）。

编号在最小可读字号下仍超出标签内框（考虑前缀、补零位数及打印校准补偿
后的尺寸）时，`/api/svg` 返回 HTTP 400，例如：

```text
编号「ABCDEFGH-0001」放不进标签「小签」：标签内框约 10×10mm，即使以 1.8mm
最小字号绘制，编号仍会越过标签边界。请缩短前缀、减小补零位数 / 起始号，
或加大标签尺寸……
```

### 补印请求示例

`POST /api/reprint` 的请求体在 `/api/svg` 的基础上把显示开关换成
`indexes`（页内标签序号，从 1 开始）：

```json
{
  "page": 1,
  "indexes": [2, 5, 9],
  "show_annotations": true,
  "params": { "page_width": 210, "page_height": 297, "labels": ["……同 /api/layout……"] },
  "calibration": null
}
```

- `indexes` 对应该页 `pages[].labels[]` 的顺序（界面预览角标 `#1` 即
  序号 1）；重复序号自动去重；
- 服务端仍先按 `params` 计算**完整原排版**，再只绘制序号 2、5、9 三个
  标签的轮廓、流水号、标注与裁切角线，坐标与编号保持原排版；
- 返回 `reprint-page-1.svg`；`indexes` 为空、序号小于 1 或大于本页
  标签数、页码超出范围时返回 HTTP 400 及明确中文原因，例如：

```text
页内标签序号 99 超出范围：第 1 页共排入 20 个标签（序号为 1–20）。
请重新生成拼版后按最新预览点选。
```

### 库存与领料请求示例

登记库存（纸宽 210、纸高 297，入库 100 张；同纸型再次调用会累加）：

```bash
curl -X POST http://localhost:8000/api/stock \
  -H 'Content-Type: application/json' \
  -d '{"paper_width": 210, "paper_height": 297, "quantity": 100}'
```

确认领料（`params` 与 `/api/layout` 请求体完全一致）：

```bash
curl -X POST http://localhost:8000/api/requisitions \
  -H 'Content-Type: application/json' \
  -d '{"order_no": "LL-20260925-001", "params": {
    "page_width": 210, "page_height": 297,
    "margin_top": 8, "margin_right": 8, "margin_bottom": 8, "margin_left": 8,
    "gap_x": 2, "gap_y": 2,
    "labels": [{"name": "品名标签", "width": 60, "height": 30, "count": 20}]
  }}'
```

首次成功返回 HTTP 201，例如：

```json
{
  "reused": false,
  "order_no": "LL-20260925-001",
  "paper_width": 210.0,
  "paper_height": 297.0,
  "pages_required": 2,
  "labels_requested": 20,
  "labels_placed": 20,
  "stock_before": 100,
  "stock_after": 98,
  "created_at": "2026-09-25T14:03:07"
}
```

- 用**完全相同的请求体**（JSON 字段顺序不影响）再次提交：返回
  HTTP 200，`reused=true` 且 `stock_before/stock_after/created_at`
  与原记录一致，余量保持 98 不变；
- 仅修改 `params`（如份数、纸宽、边距）后沿用同一 `order_no`：
  HTTP 409，`detail` 说明单号已存在但参数不同，不扣纸；
- 余量不足 / 纸型未登记：HTTP 409，`detail` 同时给出
  **所需页数、当前余量（未登记为 0 张）与差额**；
- 有标签未全部排入：HTTP 400（拼版结果仍可在页面正常预览）。

作废领料单并退纸（按原单实际扣纸页数返还；重复 / 并发调用只返还一次）：

```bash
curl -X POST http://localhost:8000/api/requisitions/void \
  -H 'Content-Type: application/json' \
  -d '{"order_no": "LL-20260925-001"}'
```

返回 HTTP 200：

```json
{
  "reused": false,
  "order_no": "LL-20260925-001",
  "paper_width": 210.0,
  "paper_height": 297.0,
  "pages_required": 2,
  "labels_requested": 20,
  "labels_placed": 20,
  "stock_before": 100,
  "stock_after": 98,
  "created_at": "2026-09-25T14:03:07",
  "status": "voided",
  "voided_at": "2026-09-25T15:10:42",
  "returned_pages": 2,
  "restock_before": 98,
  "restock_after": 100,
  "already_voided": false
}
```

- 原单原有的扣纸快照（`stock_before`/`stock_after`）与确认时间保留；
  `returned_pages` 恒等于原单实际扣纸页数 `pages_required`；
- 再次调用同一单号作废：HTTP 200 且 `already_voided=true`、
  `voided_at/returned_pages` 与首次作废一致，余量不重复增加；
- 单号不存在：HTTP 404，`detail` 提示单号不存在；
- 作废成功后再用该单号确认领料：HTTP 409，提示该单号已作废、
  不能再次用于确认领料。

> **旧版本数据库兼容**：升级后首次启动会自动对旧 `requisitions` 表
> 逐列 `ALTER TABLE` 补出 `status` / `voided_at` / `returned_pages` /
> `restock_before` / `restock_after` 列，已有领料记录自动视为
> `confirmed`（未作废、未返还），历史数据与 Docker Compose 数据卷
> 无需任何手工迁移。

数据库文件默认为项目根目录 `data/label_stock.db`，可用环境变量
`LABEL_STOCK_DB` 指定其它路径；本地开发时容器外运行会自动创建该目录。

## 本地开发（不使用 Docker）

```bash
pip install -r requirements.txt
python -m app.bootstrap          # 可选：初始化自检（含库存领料事务冒烟测试）
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

SQLite 数据库默认写入项目根目录 `data/label_stock.db`（自动创建），
设置环境变量 `LABEL_STOCK_DB=/path/to/xxx.db` 可改用其它文件路径。
